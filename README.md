## 🧭 About Me

I am a **Software Engineer** focused on **backend engineering, cloud architecture, and system design**.
I enjoy turning ambiguous requirements into services that are observable, testable, and boring to operate —
because reliability is a design decision, not an afterthought.

- 🏗️ **Backend Engineering** — designing REST APIs, domain boundaries, and data models that stay coherent as products grow.
- ☁️ **Cloud Architecture** — deploying on AWS (EC2, EBS, CloudWatch), containerizing with Docker, and treating infrastructure as a product.
- 🧩 **System Design** — reasoning about consistency, caching, queues, and failure modes before writing the first line of code.
- 🔬 **Currently exploring** — microservices decomposition patterns, event-driven architecture with Kafka, and distributed-systems trade-offs.

I care about clean contracts between services, measurable performance, and documentation that lets the next engineer move faster.
